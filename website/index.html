Mentis

Mental wellness and productivity web application. Built with React, TypeScript, and Vite.

Live App Source Code

Features

Wellness Tracking

Track mental wellness metrics and productivity over time.

React 18

Modern React with hooks and functional component architecture.

TypeScript

Full TypeScript support with strict type checking.

Vite + Tailwind

Lightning fast builds and utility-first CSS styling.

Build from Source

  1. Prerequisites: Node.js 20+, npm
  2. Clone: git clone https://github.com/cocodedk/mentis.git
  3. Install: npm install
  4. Run: npm run dev
